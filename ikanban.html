Política de Privacidade - ikanban

Última atualização: 6 de novembro de 2025

Vigência: Esta política entra em vigor na data de sua publicação.

🛡️ Compromisso com a Privacidade

O ikanban é projetado com "Privacidade por Design". Coletamos apenas dados técnicos mínimos necessários para melhorar o aplicativo (analytics e crashlytics). Seus dados pessoais e conteúdo das tarefas permanecem exclusivamente em seu dispositivo.

1. Resumo da Política

O ikanban é um aplicativo de gerenciamento de tarefas que funciona offline e coleta apenas dados técnicos essenciais para análise de uso e correção de bugs. Esta política explica detalhadamente nosso compromisso com sua privacidade e quais dados são coletados.

2. Informações Coletadas

2.1 Dados Pessoais

NÃO COLETAMOS DADOS PESSOAIS IDENTIFICÁVEIS. O ikanban não coleta, armazena ou transmite:

  • Nome, email ou informações de contato
  • Localização geográfica precisa
  • Conteúdo das suas tarefas ou projetos
  • Fotos, arquivos ou documentos pessoais
  • Informações financeiras ou de pagamento
  • Dados biométricos ou de saúde

2.2 Dados Técnicos Coletados

COLETAMOS DADOS TÉCNICOS MÍNIMOS para melhorar o aplicativo:

  • Analytics (Firebase Analytics):
    • Versão do aplicativo e sistema operacional
    • Modelo do dispositivo (anonimizado)
    • País/região (sem localização precisa)
    • Idioma do dispositivo
    • Funcionalidades mais utilizadas (sem conteúdo)
    • Tempo de sessão e frequência de uso
    • Eventos de navegação dentro do app
  • Crashlytics (Firebase Crashlytics):
    • Relatórios de crashes e erros
    • Stack traces para debugging
    • Informações do dispositivo no momento do crash
    • Versão do app quando ocorreu o erro
    • Estado do app antes do crash

2.3 Dados NÃO Coletados

GARANTIMOS QUE NÃO COLETAMOS:

  • Conteúdo das suas tarefas, notas ou projetos
  • Endereço IP específico
  • Dados de outros aplicativos instalados
  • Histórico de navegação web
  • Contatos ou agenda telefônica
  • Fotos, vídeos ou arquivos do dispositivo
  • Informações de chamadas ou SMS

3. Como Seus Dados São Armazenados

3.1 Armazenamento Local

Todos os dados que você cria no ikanban são armazenados exclusivamente:

  • No seu dispositivo: Utilizamos o banco de dados local SQLite
  • Sem sincronização: Não enviamos dados para nenhum servidor
  • Sem backup automático: Não fazemos backup de seus dados
  • Controle total: Você tem controle total sobre seus dados

3.2 Segurança dos Dados

Seus dados são protegidos pelo:

  • Sistema de permissões do Android
  • Armazenamento em área privada do aplicativo
  • Não são acessíveis por outros aplicativos
  • Removidos quando o aplicativo é desinstalado

4. Compartilhamento de Dados

4.1 Dados Compartilhados com Terceiros

COMPARTILHAMENTO LIMITADO apenas com provedores de serviços técnicos:

  • Google (Firebase):
    • Dados de analytics anonimizados
    • Relatórios de crash para correção de bugs
    • Informações técnicas do dispositivo
    • Sujeito à Política de Privacidade do Google

4.2 Dados NÃO Compartilhados

GARANTIMOS QUE NÃO:

  • Vendemos informações pessoais
  • Compartilhamos conteúdo das suas tarefas
  • Fornecemos dados para marketing direcionado
  • Integramos com redes sociais para coleta de dados
  • Compartilhamos com parceiros comerciais
  • Utilizamos dados para publicidade

5. Permissões do Aplicativo

5.1 Permissões Solicitadas

O ikanban solicita permissões mínimas:

  • Armazenamento: Para salvar seus dados localmente
  • Nenhuma outra permissão é necessária

5.2 Permissões NÃO Solicitadas

O aplicativo NÃO solicita permissões para:

  • Acesso à internet
  • Localização (GPS)
  • Câmera ou microfone
  • Contatos ou agenda
  • Chamadas telefônicas
  • SMS ou mensagens

6. Cookies e Tecnologias de Rastreamento

6.1 Tecnologias Utilizadas

UTILIZAMOS TECNOLOGIAS MÍNIMAS:

  • Firebase Analytics SDK: Para coleta de dados de uso anonimizados
  • Firebase Crashlytics SDK: Para relatórios de erro e crash
  • Identificadores de instância: Para diferenciar instalações (não pessoais)

6.2 Tecnologias NÃO Utilizadas

NÃO UTILIZAMOS:

  • Cookies de navegador web
  • Web beacons ou pixel tags
  • SDKs de publicidade ou marketing
  • Rastreamento cross-app
  • Fingerprinting de dispositivo
  • Advertising IDs para publicidade

7. Serviços de Terceiros

7.1 Serviços Integrados

INTEGRAÇÕES TÉCNICAS MÍNIMAS:

  • Google Firebase:
    • Analytics para melhorar o app
    • Crashlytics para correção de bugs
    • Política: Google Privacy Policy

7.2 Serviços NÃO Integrados

NÃO UTILIZAMOS:

  • Redes sociais para coleta de dados
  • Serviços de nuvem para armazenamento pessoal
  • SDKs de advertising ou marketing
  • Plataformas de email marketing
  • Serviços de chat ou suporte

8. Direitos do Usuário

8.1 Seus Direitos

Como usuário do ikanban, você tem o direito de:

  • Controle total: Seus dados estão exclusivamente em seu dispositivo
  • Exclusão: Desinstalar o aplicativo remove todos os dados
  • Backup: Fazer backup manual de seus dados (se desejar)
  • Não rastreamento: Usar o aplicativo sem ser rastreado

8.2 Como Exercer Seus Direitos

Para exercer seus direitos:

  • Apagar dados: Desinstale o aplicativo
  • Backup: Use as funções de exportação do aplicativo (se disponíveis)
  • Privacidade: Nenhuma ação necessária - já garantida por design

9. Proteção de Dados de Menores

O ikanban é seguro para menores de idade porque:

  • Não coleta dados pessoais de ninguém, incluindo menores
  • Não requer cadastro ou informações pessoais
  • Funciona offline sem interação externa
  • Não possui recursos de comunicação ou social
  • Não exibe publicidade

10. Transferência Internacional de Dados

TRANSFERÊNCIA LIMITADA DE DADOS TÉCNICOS:

  • Dados de analytics e crashlytics podem ser transferidos para servidores do Google (Firebase)
  • Google possui servidores em múltiplas jurisdições
  • Dados são anonimizados e não identificam usuários individualmente
  • Sujeito às proteções de privacidade do Google

SEUS DADOS PESSOAIS PERMANECEM LOCAIS: O conteúdo das suas tarefas, projetos e dados pessoais nunca saem do seu dispositivo.

11. Conformidade com Regulamentações

11.1 LGPD (Lei Geral de Proteção de Dados - Brasil)

O ikanban está em conformidade com a LGPD porque:

  • Não trata dados pessoais
  • Não há base legal necessária (não coletamos dados)
  • Não há riscos aos direitos dos titulares
  • Privacidade by design implementada

11.2 GDPR (Regulamento Geral de Proteção de Dados - Europa)

O ikanban está em conformidade com o GDPR porque:

  • Não processa dados pessoais
  • Não há necessidade de consentimento
  • Não há obrigações de DPO ou DPIA
  • Princípios de privacy by design seguidos

11.3 Google Play Store Policies

O ikanban cumpre todas as políticas da Google Play Store:

  • Política de Dados do Usuário
  • Política de Permissões
  • Diretrizes de Privacidade
  • Políticas de Conteúdo

12. Atualizações desta Política

Esta Política de Privacidade pode ser atualizada para:

  • Refletir mudanças regulamentares
  • Melhorar a clareza das informações
  • Incluir novas funcionalidades (se mantiverem a privacidade)

Mudanças serão comunicadas através de:

  • Atualização na página web oficial
  • Aviso na descrição do aplicativo na Play Store
  • Notificação dentro do aplicativo (quando aplicável)

⚠️ Importante: Backup de Dados

Como seus dados ficam apenas em seu dispositivo e não fazemos backup automático, recomendamos que você:

  • Faça backup manual regularmente de dados importantes
  • Entenda que a desinstalação remove todos os dados
  • Considere usar ferramentas de backup do Android
